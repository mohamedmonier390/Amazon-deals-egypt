# Monier Deals — الإصدار 0.5.0

تطبيق أندرويد لإدارة عروض Amazon.eg وتجهيز منشورات التسويق بالعمولة.

## المزايا الحالية
- إضافة عروض يدويًا باستخدام رابط المنتج والسعر الحالي والسعر السابق.
- حساب نسبة الخصم تلقائيًا.
- حفظ العروض محليًا على الجهاز.
- تصنيف المنتجات: إلكترونيات، موبايلات، أجهزة منزلية، ملابس وأحذية، العناية الشخصية، مستلزمات المنزل، ألعاب، رياضة، كتب، وعام.
- فلترة قائمة العروض حسب التصنيف والبحث والحد الأدنى للخصم وحالة النشر.
- ترتيب العروض حسب أعلى خصم أو الأحدث أو الأقل خصمًا.
- تحديث سعر العرض مع حفظ سجل تغيّر الأسعار.
- معاينة نص المنشور ونسخه أو مشاركته.
- منع إضافة رابط المنتج نفسه مرتين.

## حدود الإصدار
هذا الإصدار لا يتصل تلقائيًا بأمازون ولا يجلب الأسعار الحية ولا ينشر تلقائيًا. الأسعار المدخلة يدوية ويجب التحقق منها قبل النشر. الربط التلقائي يحتاج واجهة رسمية وصلاحية حساب مناسبة، كما يجب الالتزام بشروط أمازون وسياسات منصة النشر.

