# Amazon Deals Egypt — نسخة تجريبية للموبايل

هذه نسخة Android تجريبية تعمل دون Amazon API ودون Telegram Bot:
- إضافة عرض يدويًا (اسم المنتج، السعر الحالي، السعر قبل الخصم، رابط المنتج).
- حساب نسبة الخصم تلقائيًا عند إدخال السعرين.
- معاينة نص المنشور ونسخه لمشاركته يدويًا.
- البيانات محفوظة مؤقتًا أثناء فتح التطبيق فقط؛ لا يوجد تخزين دائم في هذه النسخة.

## بناء APK عبر Codemagic
1. ارفع مجلد `android` إلى مستودع GitHub.
2. اربط المستودع بحسابك في https://codemagic.io/
3. اختر Android App ثم إعداد البناء باستخدام Gradle.
4. اجعل أمر البناء `gradle assembleDebug` من مجلد `android`.
5. أضف artifact pattern: `app/build/outputs/apk/debug/app-debug.apk`
6. بعد نجاح البناء نزّل APK وثبّته على هاتف Android. قد تحتاج السماح بالتثبيت من هذا المصدر.

ملاحظة: هذه ملفات مصدر وليست APK جاهزًا. لا يحتوي المشروع على Amazon API أو Telegram Bot حتى الآن.
