# Amazon Deals Egypt / Monier Deals — نسخة مطورة 0.3.0

## ما تم تطويره في هذه النسخة
- حفظ العروض محليًا على الهاتف باستخدام SharedPreferences، وتظل موجودة بعد إغلاق التطبيق.
- منع إضافة رابط المنتج نفسه أكثر من مرة.
- التحقق من السعر الحالي والسعر السابق والرابط قبل الحفظ.
- حساب نسبة الخصم عند إدخال السعرين بشكل صحيح.
- معاينة المنشور ونسخه أو مشاركته من الهاتف.
- حذف العرض المحفوظ.

## ما لم يتم تنفيذه بعد
- لا يوجد اتصال مباشر بـ Amazon Product Advertising API.
- لا يوجد اكتشاف تلقائي للعروض أو تحديث تلقائي للأسعار.
- لا يوجد Telegram Bot أو نشر تلقائي على فيسبوك/واتساب.
- لا توجد مزامنة سحابية؛ البيانات محفوظة على نفس الهاتف فقط.
- لا تضع مفاتيح API أو كلمات مرور أو Bot Token داخل التطبيق أو المستودع.

## بناء APK عبر Codemagic
1. اربط مستودع GitHub بحساب Codemagic.
2. اختر Workflow باسم `android-debug` أو استخدم ملف `codemagic.yaml`.
3. أمر البناء في الملف هو `cd android && gradle assembleDebug`.
4. ملف APK الناتج المتوقع:
   `android/app/build/outputs/apk/debug/app-debug.apk`

هذه ملفات مصدر مطورة وليست APK جاهزًا. يجب تشغيل بناء Codemagic واختبار التطبيق على جهاز Android قبل اعتباره إصدارًا نهائيًا.
