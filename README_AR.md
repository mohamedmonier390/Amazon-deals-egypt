# Monier Deals — الإصدار 0.6.1

تطبيق أندرويد لإدارة عروض Amazon.eg وتجهيز منشورات التسويق بالعمولة.

## الجديد في 0.6.1
- استقبال رابط المنتج عند مشاركة صفحة منتج من تطبيق Amazon أو المتصفح إلى Monier Deals عبر قائمة المشاركة في أندرويد.
- تعبئة حقل الرابط تلقائيًا، ومحاولة تعبئة اسم المنتج إذا أرسله التطبيق المصدر قبل الرابط.
- بعد الاستيراد، أدخل السعر الحالي (والسعر السابق إن توفر) ثم اضغط حفظ العرض.
- قبول روابط Amazon المعروفة وروابط amzn.to فقط.

## المزايا السابقة
- إضافة عروض يدويًا باستخدام رابط المنتج والسعر الحالي والسعر السابق.
- حساب نسبة الخصم تلقائيًا وحفظ العروض محليًا.
- تصنيف المنتجات والبحث والفلترة والترتيب.
- تحديث سعر العرض مع حفظ سجل تغيّر الأسعار.
- معاينة نص المنشور ونسخه أو مشاركته.
- منع إضافة رابط المنتج نفسه مرتين.

## حدود الإصدار
هذه الخاصية تستورد الرابط من قائمة المشاركة فقط؛ لا تستخرج السعر أو تفاصيل المنتج تلقائيًا، ولا تبحث عن العروض بنفسها. لا يتصل هذا الإصدار تلقائيًا بأمازون ولا ينشر تلقائيًا. يجب إدخال السعر والتحقق منه قبل النشر. الربط التلقائي يحتاج واجهة رسمية وصلاحية حساب مناسبة، كما يجب الالتزام بشروط أمازون وسياسات منصة النشر.

## طريقة الاستخدام
1. افتح تطبيق Amazon أو المتصفح.
2. افتح صفحة المنتج المطلوبة.
3. اضغط مشاركة (Share).
4. اختر Monier Deals.
5. راجع اسم المنتج والرابط، وأدخل السعر الحالي ثم احفظ.

## إصلاح 0.6.1
- تحسين استقبال الروابط من مشاركة النص أو عنوان المشاركة أو URI في ClipData.
- قبول نطاق amazon.eg ونطاقات أمازون المعروفة مع إزالة www من فحص النطاق.
- تعيين اسم افتراضي عند مشاركة رابط فقط دون عنوان منتج.
- هذا لا يستخرج السعر أو اسم المنتج الحقيقي من أمازون؛ يلزم إدخالهما/مراجعتهما يدويًا.
